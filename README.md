# Farm Feather Bridge

Native Android app (Kotlin + XML Views), generated by Android App Factory.

- Gradle 9.6.0 wrapper, AGP 9.4.1, versions in `android/gradle/libs.versions.toml`
- Gradle root: `android/` — `cd android && ./gradlew assembleRelease bundleRelease`
- Sources: `android/app/src/main/java/<package>/`
- UI: XML layouts + AppCompat + Material Components, Single Activity + Fragments + ViewModels
- Images: `android/app/src/main/res/drawable/`
- Keep rules: `android/app/src/main/keepRules/rules.keep`
